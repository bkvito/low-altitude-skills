# Skill 合集仓库骨架搭建实施方案

## 任务目标

本次任务是在当前目录搭建一个轻量的 Skill 合集仓库骨架，让后续可以直接开始编写具体 Skill。

## 实施范围

本次创建以下基础文件和目录：

```text
README.md
AGENTS.md
LICENSE.md
skills/_template/SKILL.md
skills/_template/references/overview.md
```

## 结构设计

仓库根目录用于放置项目说明、协作规则和许可证说明。

`skills/` 用于存放所有 Skill，每个正式 Skill 后续都应使用独立目录。

`skills/_template/` 作为新 Skill 的复制模板，避免每次从零创建 `SKILL.md` 和 `references/`。

## 文件职责

`README.md`：说明仓库用途、目录结构、新增 Skill 流程和 Skill 列表。

`AGENTS.md`：定义 AI Agent 在本仓库中的协作规则，包括目录规范、文档规范、验证要求和 Git 要求。

`LICENSE.md`：先放置默认版权说明，等正式开源发布前再替换为明确许可证。

`skills/_template/SKILL.md`：提供新 Skill 的入口文件模板。

`skills/_template/references/overview.md`：提供 Skill 详细说明文档模板。

## 验证方式

本次验证包括：

1. 检查新增文件是否存在。
2. 使用 UTF-8 读取关键 Markdown 文件，确认中文内容正常。
3. 检查 `skills/_template/references/overview.md` 路径是否存在。
4. 查看 Git 状态，确认新增文件被识别。

## 后续计划

下一步可以复制 `skills/_template/` 创建真实 Skill，例如：

```text
skills/vue/
skills/pinia/
skills/project-rules/
```

每个 Skill 创建后，需要更新 `README.md` 中的 Skill 列表。
